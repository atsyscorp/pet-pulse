# Surface brief: public site (landing, login, solicitar acceso)

Scope: Persuade (landing), Operate-lite (login, access request form). Visitor mode per surface.

Audience: clinic owners/managers evaluating; staff signing in. Action: request access or demo; sign in.
Content: existing landing copy and sections preserved; no invented customers, prices, trials.
Constraints: Outfit self-hosted; light/dark/system toggle, default light; 48px targets; WCAG AA; reduced motion.

## Direction contract

THESIS: A calm, sober clinical surface with one living vital-signs trace; refuses the neon-glow-on-night SaaS default and the icon-card grid.
OWN-WORLD: Paper/white tonal layers, night-indigo ink and primary action; cyan only as the ECG line and dark-theme fill; hairline borders, no shadows, no glow; Outfit with tabular numerals; 12-24px radii; specimens of real kardex states drawn in-page.
STORY: Visitor sees a monitor tracing a pulse beside a real-looking kardex readout, understands PetPulse counts every dose to 0.0001 mL in real time, and requests access or signs in.
FIRST VIEWPORT: Left: headline (Display), paragraph, primary "Solicitar acceso" and secondary "Iniciar sesión". Right: a monitor panel on a Raised Night screen (dark in both themes) with animated ECG sweep and a labeled-synthetic dose readout. Nav 64px with theme toggle.
FORM: Split hero with a monitor instrument; features as ruled rows with drawn specimens; steps joined by a trace line. Direct composition (no concept tournament: world settled by DESIGN.md).
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
